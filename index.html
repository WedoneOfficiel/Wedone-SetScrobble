ACCÈS VERROUILLÉ

Connexion à Last.fm obligatoire

SetScrobble envoie tes écoutes à ton compte Last.fm. Tant que ce compte n'est pas connecté, aucun module n'est accessible. Suis les quatre étapes ci-dessous : cela ne prend que quelques minutes.

Étape 1 sur 4
01

Créer une application Last.fm

Crée gratuitement ton application API depuis ton compte Last.fm. Tu y récupèreras ta clé API et ton secret.

Créer mon application ↗
02

Renseigner les clés API

Copie la clé API et le secret fournis par Last.fm, puis enregistre-les.

03

Autoriser Wedone

Last.fm s'ouvre dans un nouvel onglet : accepte l'accès demandé pour ton compte, puis reviens ici.

04

Finaliser la connexion

Une fois l'autorisation acceptée, valide la connexion. Tu arriveras directement sur Scrobble rapide.
